# The Orchard: Resto Lounge & Social House

React + Vite, multi-page (React Router, hash-based so it works on any static host with no config).

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Pages: Home, The House, Spaces, Menus, Visit & Reservations.
Edit menus, hours and spaces in `src/data.js`. The reservation form currently logs to the console; connect it in `src/pages/Visit.jsx`.
Placeholders to replace: address, phone, email.
